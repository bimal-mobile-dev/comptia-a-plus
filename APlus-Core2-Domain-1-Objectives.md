## Windows operating system fundamentals

- **Windows 11 administration**: V15's expanded focus — installation methods, editions, and administrative tools (Task Manager, Device Manager, Disk Management, Control Panel/Settings) specific to the current Windows version rather than legacy Windows releases
- **Command-line tools**: common Windows command-line utilities used for diagnostics and configuration — a frequent PBQ format tests correctly identifying or using the right command for a described task

## macOS and Linux

- **macOS**: basic administration, common tools, and how its file system/security model differs from Windows at a support-relevant level
- **Linux**: basic command-line navigation and common administrative tasks — introductory-level Linux support skill (the CompTIA Linux+ guide in this collection covers Linux far more deeply)

## OS installation and configuration

- **Installation methods**: clean install, upgrade, and imaging/deployment approaches, and choosing the appropriate method for a described scenario
- **Application and driver management**: installing, updating, and troubleshooting applications and device drivers across the supported operating systems
