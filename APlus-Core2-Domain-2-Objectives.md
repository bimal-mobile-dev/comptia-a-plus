- **28% weighting — tied for the heaviest Core 2 domain,** reflecting V15's stronger endpoint security emphasis. This is a support technician's practical security toolkit, distinct from (and a prerequisite step toward) the dedicated depth of Security+

## Physical and endpoint security

- **Physical security controls**: locks, badge access, and secure hardware disposal — practical, technician-level implementation rather than enterprise security architecture
- **Endpoint security**: antivirus/anti-malware deployment and configuration, host firewalls, and basic endpoint hardening

## Authentication and access control

- **Windows authentication and permissions**: user accounts, groups, and file/folder permission concepts at a Windows-administration level
- **MFA and modern authentication awareness**: recognizing and troubleshooting basic multi-factor authentication issues a support technician commonly encounters (e.g., a user locked out after an MFA device change)

## Malware and social engineering

- **Common malware types and symptoms**: recognizing what a described set of symptoms (unexpected pop-ups, slow performance, unfamiliar processes) most likely indicates, and the correct first response
- **Social engineering awareness**: recognizing phishing and other social engineering attempts, and understanding a support technician's role in both preventing and responding to them

## Wireless and network security basics

- **Securing SOHO networks**: applying basic wireless security (WPA3, disabling unnecessary services) when configuring or troubleshooting a small network, connecting back to Core 1's Networking domain
- **Data destruction and disposal**: securely wiping or destroying data on decommissioned hardware — a practical technician responsibility with real compliance implications
