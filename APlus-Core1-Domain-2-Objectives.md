- **23% weighting.** Practical, support-technician-level networking — configuring and troubleshooting real small networks, not designing enterprise architecture (that depth comes later, in Network+)

## Core protocols and services

- **TCP vs. UDP**: TCP is connection-oriented and reliable (used when data integrity matters, e.g., file transfer); UDP is connectionless and faster but doesn't guarantee delivery (used for time-sensitive traffic like video/voice) — a foundational, frequently tested distinction
- **Services provided by networked hosts**: recognizing common network services (DNS, DHCP, file/print sharing, web servers) and their basic function on a network

## Wireless networking

- **Wireless networking technologies and standards**: Wi-Fi standards, frequency bands, and basic wireless security protocols — practical configuration knowledge for setting up a functioning wireless network

## Network configuration and hardware

- **Common network configuration concepts**: IP addressing, subnetting basics, and DNS/DHCP configuration at a support-technician level
- **Networking hardware devices**: routers, switches, access points, and modems — recognizing each device's role and correctly placing it within a network topology

## SOHO network setup and internet connectivity

- **Configuring SOHO (Small Office/Home Office) networks**: a scenario-based objective — given a described wired/wireless SOHO setup, correctly configure it, a common PBQ format
- **Internet connection and network types**: DSL, cable, fiber, and satellite connections, and the general characteristics (speed, latency, reliability) of each
