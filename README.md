# CompTIA A+ (220-1201/1202) Study Resources

Material and resources for pursuing CompTIA A+ certification — built from the current **220-1201 (Core 1) and 220-1202 (Core 2), V15** exam objectives, current as of September 2026.

## A note on currency

**220-1201 and 220-1202 (V15) have been the live A+ exams since March 25, 2025**, replacing the retired 220-1101/220-1102 pair (retired September 2025). If a study resource still references 220-1101 or 220-1102, it's teaching the retired predecessor — domain weights, and some content (stronger Windows 11 focus, more virtualization/cloud, more wireless complexity, and basic AI literacy awareness) genuinely changed in V15, not just the exam codes. V15 is estimated to remain the live version through roughly September 2028.

## Overview

- **Who is it for?** The industry-standard entry point into hands-on IT support roles — help desk, technical support specialist, field technician, and junior system administrator positions. DoD 8140 approved for technical support specialist, system administrator, and cyber defense infrastructure support specialist work roles.
- **Two separate exams, both required**: Core 1 (220-1201) covers hardware, networking, mobile devices, virtualization/cloud, and troubleshooting; Core 2 (220-1202) covers operating systems, security, software troubleshooting, and operational procedures. You must pass **both** to earn the certification, and they're scored and passed independently.
- **Exam format**: up to 90 questions per exam, 90 minutes each, multiple-choice (single and multiple response), drag-and-drop, and performance-based questions (PBQs). Passing scores differ by core: **675/900 for Core 1**, **700/900 for Core 2**.
- **Certification validity**: 3 years from the date earned, after which renewal (via CompTIA's Continuing Education program) is required to keep the credential active.
- **Domain weights (V15):**

| Core 1 (220-1201) Domain | Weight |
|---|---|
| Mobile Devices | 13% |
| Networking | 23% |
| Hardware | 25% |
| Virtualization and Cloud Computing | 11% |
| Hardware and Network Troubleshooting | 28% |

| Core 2 (220-1202) Domain | Weight |
|---|---|
| Operating Systems | 28% |
| Security | 28% |
| Software Troubleshooting | 23% |
| Operational Procedures | 21% |

- **Test-taking strategies**
  - Troubleshooting is the single heaviest domain on Core 1 (28%) — CompTIA explicitly moved this exam toward a "support workflow" test rather than an IT-glossary test, so practice diagnosing symptoms and connecting them to the right subsystem, not just naming parts
  - On Core 2, Operating Systems and Security are tied at 28% each, together well over half the exam — prioritize both equally rather than favoring one
  - PBQs are the hardest question type and carry variable, undisclosed weight — pay close attention to granular technical details while studying (exact port numbers, specific error messages) since PBQs reward that precision more than the multiple-choice questions do
