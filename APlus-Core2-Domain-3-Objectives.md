- **23% weighting.** The scenario-based application of Domain 1's OS knowledge — diagnosing and resolving described software/OS problems

## OS-level troubleshooting

- **Common Windows/macOS/Linux symptoms**: slow performance, application crashes, boot failures, and update-related issues — matching described symptoms to their most likely underlying cause
- **Startup and boot troubleshooting**: recognizing and resolving common startup failures, including when a described symptom points to a corrupted OS component versus a hardware failure (connecting back to Core 1's Troubleshooting domain)

## Application and malware troubleshooting

- **Application-specific issues**: diagnosing why a specific application fails to launch, crashes, or behaves unexpectedly, and the correct escalation/resolution path
- **Malware removal**: the correct procedural steps for identifying, isolating, and removing malware from an infected system — a scenario-heavy topic that builds directly on Domain 2's malware recognition content

## Mobile OS troubleshooting

- **Common mobile OS issues**: diagnosing connectivity, application, and performance issues specific to iOS and Android devices, distinct from desktop OS troubleshooting
